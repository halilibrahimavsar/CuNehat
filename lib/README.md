# CuNehat

## Uygulama Mimarisi ve Başlatma Akışı

Uygulama, bağımlılıkları ve durumu yönetmek için `main.dart` içerisinde 3 temel katmana ayrılmıştır. Aşağıdaki diyagram bu akışı özetlemektedir:

```

│                  1. GLOBAL SCOPE (main.dart)                 │
```
